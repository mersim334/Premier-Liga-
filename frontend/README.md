# Frontend — Premier liga (demo)

React + TypeScript + Vite. API u razvoju: `VITE_API_BASE_URL` (vidi `.env.example`).

## Pokretanje

Iz **korijena repozitorija** (preporučeno):

```powershell
powershell -ExecutionPolicy Bypass -File .\dev\frontend.ps1
```

Ili ručno:

```powershell
cd frontend
npm install
npm run dev
```

Cjelokupno uputstvo (setup, mock API, PostgreSQL): **[../POKRETANJE.md](../POKRETANJE.md)**

## Build

```powershell
npm run build
```

Izlaz u `frontend/dist/`.
